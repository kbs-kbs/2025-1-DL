# 12주차 — 설명 가능한 딥러닝 모델 만들기 (XAI)

> 교재 「모두의 딥러닝」 21장 + `설명가능한 인공지능 개념 이해` 교안 · 12주차 수업 내용 정리

## 1. 왜 설명이 필요한가

- 딥러닝으로 알츠하이머형 치매 여부를 판단하는 모델은 정확도가 상당히 높다. 하지만 실제 의료 현장에서 쓰려면 **왜 그런 결과가 나왔는지 설명하는 단계**가 꼭 필요하다.
- "그냥 딥러닝이 그러더군요"라는 설명을 받아들일 환자는 없다. 다차원 입력의 계산 복잡성, 드러나지 않는 은닉층 때문에 중간 과정을 유추하기 어렵다.
- 예측 근거를 알 수 있다면 ① 사용자에게 설명할 수 있고 ② 더 나은 모델과 더 좋은 데이터를 준비하는 데도 도움이 된다.
- 이런 기술을 **설명 가능한 인공지능(XAI, eXplainable AI)** 이라고 한다.
  - 예: 말티즈 사진에서 **눈과 코**가 밝게 표시되면, 모델이 그 부분을 보고 판단했다는 근거가 된다.
  - 인공지능의 판단 근거가 없으면 신뢰하기 어렵고, 적대적 공격(adversarial attack)에 속아도 원인을 알 수 없다(STOP 표지판에 잡음을 넣어 속도 제한으로 인식시킨 사례, 2019년 테슬라 자율주행 역주행 실험 등).
  - 유럽연합 GDPR은 "시스템의 결정에 대한 설명을 요구할 수 있는 권리"를 입법화했다.

## 2. 설명하는 두 가지 방법

### ① 특징 맵을 이용하는 방법 — CAM(Class Activation Map)

- CNN은 2D 이미지를 1차원으로 축소하며 공간 정보가 손실되므로, **Flatten 직전의 중간 맵**에는 입력의 속성이 잘 간직되어 있다.
- CAM의 절차
  1. `Flatten` 직전에서 중간 맵들을 모은다.
  2. 각 중간 맵의 **평균값(Global Average Pooling, GAP)** 을 뽑는다.
  3. 그 평균값과 최종 예측 사이에서 한 번 더 학습해 **가중치**를 얻는다(어떤 중간 맵이 결정에 큰 역할을 했는지).
  4. 가중치를 각 중간 맵에 곱해 특징 맵을 만든다 → 중요한 맵은 강조되고 불필요한 맵은 사라진다.
- 모델 구조를 바꿔야 하는 번거로움을 피하려고, 평균값 대신 **기울기(gradient)** 를 쓰는 **그레이디언트 CAM(Gradient CAM)** 도 개발되었다.

### ② 일부를 가리는 방법 — 마스크 / 오클루전(폐쇄성 민감도, Occlusion Sensitivity)

- 이미지 일부를 가리고, 가려진 부분이 결과에 얼마나 영향을 미치는지 계산한다.
- 가리는 사각형(패치)을 옮겨 가며 결과 변화를 지도처럼 그린다.

## 3. 실습 — tf-explain

```python
# 코랩에는 OpenCV가 기본 제공되므로 tf-explain만 설치
!pip install tf-explain
# 주피터 노트북이라면 OpenCV도 설치
# !pip install opencv-python
```

```python
from tf_explain.core.grad_cam import GradCAM
from tf_explain.core.occlusion_sensitivity import OcclusionSensitivity
from tensorflow.keras.applications import VGG16

# 이미지넷으로 학습된 모델을 우리 모델로 사용
model = VGG16(weights='imagenet', include_top=True)

# ① 그레이디언트 CAM
explainer = GradCAM()
grid = explainer.explain(
    validation_data=(img, None),
    model=model,
    class_index=class_index          # 이미지넷 클래스 번호
)
explainer.save(grid, './xai_output/', 'grad_cam.png')
```

```python
# ② 오클루전(폐쇄성 민감도) — explain() 인자에 패치 크기가 추가된다
explainer = OcclusionSensitivity()
grid = explainer.explain(
    validation_data=(img, None),
    model=model,
    class_index=class_index,
    patch_size=40                    # 가리는 검은 사각형의 크기
)
explainer.save(grid, './xai_output/', 'occlusion.png')
```

- `explain()`에는 데이터, 모델, 이미지넷 클래스 번호가 들어가고, `save()`에는 결과, 저장 폴더, 파일명이 들어간다.
- `patch_size`가 크면 넓은 범위의 결과, 작으면 더 세밀한 결과가 나온다(예: 40 vs 20).

## 4. 결과 해석

- 히트맵에서 색이 밝을수록 예측에 많이 기여한 부분, 파란색에 가까울수록 기여가 적은 부분이다.
- CAM 계열은 모델이 "어디를 보는지"를, 오클루전은 "어디를 가리면 판단이 흔들리는지"를 보여 준다.

## 5. 시험 대비 정리

| 질문 | 답 |
|---|---|
| XAI란 | 예측의 근거를 설명해 주는 기술 |
| CAM의 원리 | Flatten 직전 중간 맵 + GAP + 가중치 → 특징 맵 |
| Gradient CAM | 평균 대신 기울기 사용, 구조 변경 불필요 |
| 오클루전 | 일부를 가리고 영향도 계산, `patch_size`로 민감도 조절 |
| 필요한 라이브러리 | `tf-explain`(+OpenCV) |
