## 1. 왜 전이 학습인가

- 딥러닝은 기존 머신 러닝과 달리 **스스로 중요한 속성을 뽑아 학습**하므로 비교적 많은 데이터가 필요하다. 좋은 성과를 내려면 코드보다 **데이터를 모으는 일**이 더 중요하다.
- 데이터가 충분하지 않을 때 쓰는 방법이 **전이 학습(transfer learning)** — 수만~수백만 장의 기존 이미지에서 학습한 **가중치를 가져와** 내 프로젝트에 활용하는 것이다. 컴퓨터 비전·자연어 처리 모두에서 널리 쓰인다.
- 원리: 딥러닝은 학습 초반에 "어떤 픽셀 조합이 선이고 면인지" 같은 기본 형태를 익히는 데 많은 시간을 쓴다. 대규모 데이터로 이미 익힌 그 표현을 가져오면, 적은 데이터로도 **더 높은 정확도에서 시작**하고 **학습도 빨라진다.**

## 2. 실습 ① 소규모 데이터셋으로 만드는 모델 (MRI 치매 분류)

### 데이터
- 총 280장(치매 140 + 일반인 140), train 160장 / test 120장
- `train/`, `test/` 폴더 아래 `ad/`, `normal/` 폴더로 클래스가 나뉜 구조
- 정답(클래스)이 주어지므로 **지도 학습**, 이미지 분류이므로 **CNN** 선택

### 데이터 부풀리기 — ImageDataGenerator

```python

train_datagen = ImageDataGenerator(rescale=1./255,   # 0~255 → 0~1 정규화
    horizontal_flip=True,     # 수평 대칭
    width_shift_range=0.1,    # 좌우로 조금씩 이동
    height_shift_range=0.1,
    #rotation_range=5, shear_range=0.7, zoom_range=[0.9,2.2],
    #vertical_flip=True, fill_mode='nearest'
)

train_generator = train_datagen.flow_from_directory(
    './data-ch20/train',
    target_size=(150,150),
    batch_size=5,
    class_mode='binary'
)

# 테스트셋은 이미지 부풀리기를 하지 않고 정규화만
test_datagen = ImageDataGenerator(rescale=1./255)
test_generator = test_datagen.flow_from_directory(
    './data-ch20/test', target_size=(150,150), batch_size=5, class_mode='binary'
)
```

- 주요 인자: `rescale`(정규화), `horizontal_flip`/`vertical_flip`(대칭), `zoom_range`(확대·축소), `width_shift_range`/`height_shift_range`(평행 이동), `rotation_range`(회전), `shear_range`(전단 변환), `fill_mode`(빈 공간 채우기)
- 모든 인자를 다 적용하면 불필요한 데이터가 생겨 학습 시간만 늘어난다. **데이터 특성에 맞게 골라 쓴다.** (뇌 사진은 좌우 차이가 중요하지 않으므로 `horizontal_flip`)
- **데이터 부풀리기는 학습셋에만** 적용한다. 테스트셋은 실제 정보를 그대로 두는 편이 과적합 위험을 줄인다.

## 3. 실습 ② 전이 학습 적용 — VGG16

- **이미지넷(ImageNet)**: 1,000가지 종류, 120만 장이 넘는 이미지 데이터셋(ILSVRC 대회). 전체 200GB 규모.
- **VGGNet**: 옥스포드 VGG 팀이 만든 모델로 2014년 ILSVRC 2위. 층 구성에 따라 VGG16, VGG19로 불리며 여기서는 VGG16 사용.
- 케라스는 VGG 외에도 `ResNet`, `Inception`, `MobileNet`, `DenseNet` 등을 `keras.applications`에서 제공한다.

```python
from tensorflow.keras.applications import VGG16

# 이미지넷으로 미리 학습된 VGG16 불러오기
transfer_model = VGG16(weights='imagenet', include_top=False, input_shape=(150,150,3))
transfer_model.trainable = False      # 가져온 부분은 새로 학습하지 않음

# 내 프로젝트용 네트워크를 뒤에 붙임 (미세 조정)
finetune_model = models.Sequential()
finetune_model.add(transfer_model)
finetune_model.add(Flatten())
finetune_model.add(Dense(64))
finetune_model.add(Activation('relu'))
finetune_model.add(Dropout(0.5))
finetune_model.add(Dense(1))
finetune_model.add(Activation('sigmoid'))
finetune_model.summary()
```

| 옵션 | 의미 |
|---|---|
| `weights='imagenet'` | 이미지넷으로 학습된 가중치를 가져옴 |
| `include_top=False` | VGG16의 마지막 분류층(1000개 클래스)은 가져오지 않음 — 우리 데이터는 2클래스 |
| `transfer_model.trainable = False` | 가져온 층은 동결 (학습 가능한 파라미터 0개) |

- `summary()`를 보면 vgg16 부분의 **14,714,688개 파라미터는 그대로 유지**되고, 뒤에 붙인 `Dense(64)`(524,352개) 등 **분류를 위한 부분만 새로 학습**된다.
- 이후 `fit()`에 `train_generator`/`test_generator`를 넣고 조기 중단을 설정해 학습한다.

### 결과 비교

| 모델 | 시작 정확도 | 특징 |
|---|---|---|
| 직접 만든 CNN | 50% | 학습이 느리고 곡선이 불안정 |
| **VGG16 전이 학습** | **78%** | 더 높은 정확도에서 시작, 학습 속도 빠름, 그래프 변화 안정적 |

## 4. 정리

1. 데이터가 적으면 **데이터 부풀리기 + 전이 학습**을 함께 쓴다.
2. 전이 학습 = 대규모 데이터로 학습된 **앞쪽 층(특징 추출기)** 을 가져오고 **뒤쪽 분류층만 새로 학습**.
3. `include_top=False`, `trainable=False`가 핵심 옵션이며, 필요하면 일부 층을 풀어 **미세 조정(fine tuning)** 한다.
