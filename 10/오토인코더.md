## 1. 오토인코더(Auto-Encoder, AE)란

- 가상의 이미지를 만드는 또 하나의 알고리즘. GAN과 결과는 비슷해 보이지만 **성질이 다르다.**

| 구분 | GAN | 오토인코더 |
|---|---|---|
| 만드는 것 | 세상에 **존재하지 않는** 완전한 가상 이미지 | 입력 데이터의 **특징을 효율적으로 담아낸** 이미지 |
| 얼굴 예시 | 진짜 같지만 실존하지 않는 얼굴 | 초점은 흐릿하고 윤곽이 불명확하지만 사람의 특징이 모여 있는 이미지 |
| 학습 난이도 | 생성자·판별자의 경합이라 어렵다 | 훨씬 쉽다 |

- **구조**: 입력(X)과 출력(X′) 사이에 **입력보다 노드 수가 적은 은닉층**을 넣어 차원을 줄인다. 줄어든 차원에서 소실된 데이터를 복원하도록 학습하면서, 입력의 특징을 응축한 출력이 나온다.
  - 차원을 줄이는 부분 = **인코딩(encoding)**
  - 다시 늘려 입력과 같은 크기로 되돌리는 부분 = **디코딩(decoding)**
- **활용**: 영상 의학처럼 데이터가 충분하지 않은 분야에서 **학습 데이터 수를 효과적으로 늘리는** 용도. 존재하지 않는 가상 데이터를 넣으면 예측치 못한 결과가 나올 수 있지만, 특징을 잘 담아낸 오토인코더라면 안전하게 데이터를 보강할 수 있다.

## 2. 모델 구조 (MNIST 28×28 기준)

```python
# 오토인코더 모델 만들기
autoencoder = Sequential()

# 인코딩 부분
autoencoder.add(Conv2D(16, kernel_size=3, padding='same', input_shape=(28,28,1), activation='relu'))
autoencoder.add(MaxPooling2D(pool_size=2, padding='same'))
autoencoder.add(Conv2D(8, kernel_size=3, activation='relu', padding='same'))
autoencoder.add(MaxPooling2D(pool_size=2, padding='same'))
autoencoder.add(Conv2D(8, kernel_size=3, strides=2, padding='same', activation='relu'))

# 디코딩 부분
autoencoder.add(Conv2D(8, kernel_size=3, padding='same', activation='relu'))
autoencoder.add(UpSampling2D())
autoencoder.add(Conv2D(8, kernel_size=3, padding='same', activation='relu'))
autoencoder.add(UpSampling2D())
autoencoder.add(Conv2D(16, kernel_size=3, activation='relu'))   # padding 없음 → 크기 2 감소
autoencoder.add(UpSampling2D())
autoencoder.add(Conv2D(1, kernel_size=3, padding='same', activation='sigmoid'))

# 전체 구조 확인
autoencoder.summary()
```

### 크기 계산에서 헷갈리는 부분

- 인코딩에서 `MaxPooling2D`가 **두 번**, 디코딩에서 `UpSampling2D`가 **세 번** 나온다. 이대로면 28×28보다 커지는 것 아닌가?
- 답은 ⑩ `Conv2D(16, kernel_size=3)` 에 있다. 이 층에는 **`padding` 옵션이 없다.**
  - 패딩이 없으면 3×3 커널이 훑고 지나가면서 가로·세로 크기가 **2씩 줄어든다**(28 → 26).
  - 그래서 MaxPooling 2회(÷4)와 UpSampling 3회(×8)의 불균형이 마지막 Conv2D에서 보정되어, 최종 출력이 입력과 같은 **28×28**이 된다.
- 컴파일·학습은 16장 MNIST 분류와 같은 방식(`binary_crossentropy` 계열, 정답은 입력 이미지 자신)으로 진행한다.

## 3. 실행 결과

- 첫 번째 줄이 테스트에 사용한 원본 이미지, 두 번째 줄이 원본의 특징을 고스란히 담아 복원된 오토인코더 이미지다.
- 숫자의 윤곽이 흐릿해지지만 형태는 유지되는 것을 확인할 수 있다.

## 4. GAN과 오토인코더 비교 정리

| 항목 | GAN | 오토인코더 |
|---|---|---|
| 학습 방식 | 생성자 ↔ 판별자 **적대적 경합** | 입력 → 축소 → 복원 (**자기 자신을 정답으로**) |
| 목적 | 진짜 같은 **새 데이터 생성** | 데이터의 **특징 추출·복원** |
| 손실 | 판별자/생성자 손실 2개 | 복원 오차 1개 |
| 대표 활용 | 얼굴 생성, 화풍 변환, 이미지 변환 | 노이즈 제거, 차원 축소, 의료 데이터 증강 |
