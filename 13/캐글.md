## 1. 캐글(Kaggle)이란

- 2010년 4월부터 전 세계 데이터 과학자 **15만 명 이상**이 참가해 온 데이터 분석 경진대회 플랫폼.
- "데이터 사이언스를 스포츠처럼!" — 각 대회마다 과제, 평가 지표, 실제 데이터가 주어진다.
- 분석 결과를 업로드하면 보통 **몇 분 안에 채점**되고, 평가 지표에 따라 순위가 매겨진다.
- 15장에서 사용한 주택 가격 데이터가 사실은 캐글에서 배포하는 유명 벤치마크 학습셋이다. 여기서는 그때 학습한 모델의 결과를 **캐글에 제출**해 본다.

## 2. 진행 순서

1. 캐글 가입 (구글 계정으로 간단히 가입) → `Competitions`
2. 대회 선택: **House Prices - Advanced Regression Techniques**
   - https://www.kaggle.com/c/house-prices-advanced-regression-techniques
3. 데이터 획득: `Data` → `I understand and agree` → `Download All`
4. 학습 → 제출 파일 만들기 → `Submit Predictions`
5. 마감 대회라면 `My Submissions`에서 `Use for Final Score`로 최종 제출

## 3. 내려받는 데이터

| 파일 | 내용 |
|---|---|
| `data_description.txt` | 각 속성의 의미 설명 |
| `train.csv` | 집 값(SalePrice)과 속성 |
| `test.csv` | train과 같은 항목이지만 **SalePrice만 빠져 있음** → 이 값을 예측하는 것이 과제 |
| `sample_submission.csv` | `Id`, `SalePrice` 두 열만 존재 — 예측값을 채워 업로드 |

## 4. 학습 → 제출 파일 만들기

테스트셋도 **학습셋과 똑같은 상태로 전처리**해야 모델을 적용할 수 있다.

```python
from tensorflow.keras.models import load_model
import pandas as pd
import numpy as np
import datetime

# 캐글에서 배포하는 테스트셋 불러오기
K_test = pd.read_csv("./data/house_test.csv")

# ① 카테고리형 변수를 0/1로 변환 (학습셋과 동일하게)
K_test = pd.get_dummies(K_test)

# ② 결측치를 전체 칼럼 평균으로 대체
K_test = K_test.fillna(K_test.mean())

# ③ 학습에 사용한 열만 남김 (순서 포함)
K_test = K_test[['열1', '열2', ...]]   # 15장에서 만든 학습 데이터의 열 구성

# ④ 15장에서 저장한 모델 불러와 예측
model = load_model("./data/model.h5")
prediction = model.predict(K_test)

# ⑤ 현재 시간으로 파일명을 만들어 별도 폴더에 저장
now = datetime.datetime.now()
now = now.strftime("%Y%m%d-%H%M%S")
submission = pd.DataFrame({'Id': test_id, 'SalePrice': prediction[:, 0]})
submission.to_csv(f'./submission/{now}_submission.csv', index=False)
```

- 실행 후 `(연도)(월)(일)-(시)(분)(초)_submission.csv`가 만들어지면 제출 준비 완료.
- 모델은 15장에서 `ModelCheckpoint`로 저장해 둔 파일을 `load_model()`로 불러온다.
- 제출 전에 **모델 설명을 간단히 적어 두면** 나중에 어떤 제출본이었는지 확인하기 좋다.

## 5. 제출 결과 확인과 활용

- `Make Submission` → `Jump to your position on the leaderboard`에서 정확도와 순위, 이전 제출과의 차이를 확인한다.
- `Code`·`Discussion` 메뉴에서 다른 참가자의 코드와 토론을 읽으면 새 기술과 조언을 얻을 수 있다.
- 실제 대회는 **하루 제출 횟수 제한**이 있으므로 전략을 세워야 한다.
- 학습용 대회는 `Public Score`만 보이지만, 상금·마감이 있는 실제 대회에는 `Use for Final Score` 열이 있다. 최종 결과를 제출하면 며칠 뒤 전체 참가자 합산 순위가 발표된다.

## 6. 요약

1. 캐글 = 실제 데이터로 기술을 겨루는 대회 플랫폼.
2. 테스트셋은 **학습셋과 동일한 전처리**가 핵심(더미 변수, 결측치 평균 대체, 열 순서).
3. 학습한 모델을 `load_model()`로 불러와 `predict()` → `Id`/`SalePrice` 형식 CSV로 저장 → 제출.
