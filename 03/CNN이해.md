## 보강 — 3주차 CNN 개념 정리

> `합성곱신경망(CNN).pptx`(개념 이해 교안)와 교재 16장을 함께 정리했습니다.

### 1. 왜 CNN인가

- 이미지(28×28=784 픽셀)를 1차원 배열로 펴서 넣으면 **위상 구조(모양)가 사라진다.** 0이라는 글자의 "수평선 + 수직선" 같은 공간 구조를 학습할 수 없다.
- 사람의 시각 피질 연구(허블·위즐, 1950년대 말)에서 **수용장(receptive field)** 개념이 나왔다. 어떤 뉴런은 수평선에, 어떤 뉴런은 수직선에 반응하고, 더 큰 수용장의 뉴런이 그 결과를 조합해 패턴을 인식한다(V1 모서리·직선 → V2 형상 → V3 객체 → IT 추상화).
- CNN은 이 계층적 처리 방식을 **커널(필터) 연산**으로 구현한 것이다.
- 기존 머신 러닝은 사람이 특징을 손으로 추출(feature engineering)해야 했지만, CNN은 **특징 추출까지 스스로 학습**한다.

### 2. 합성곱 연산

- 입력 이미지 위로 **커널(슬라이딩 윈도)** 을 한 칸씩 옮기며, 겹치는 부분의 값 × 가중치를 모두 더해 새 값을 만든다.
- 이렇게 만들어진 층이 **컨볼루션 층**이고, 그 결과 행렬이 **특징 맵(feature map)** 이다.
- 커널을 여러 개 쓰면 여러 개의 특징 맵이 만들어진다(예: 32개, 64개).
- `Conv2D(32, kernel_size=(3,3), input_shape=(28,28,1), activation='relu')`
  - 첫 인자 = 커널 수, `kernel_size` = 커널 크기, `input_shape` = (행, 열, 색상=3/흑백=1)
- **패딩(padding)**: 컨볼루션을 거치면 크기가 줄어든다. `padding='same'`은 모자란 부분을 0으로 채워 크기를 유지한다.

### 3. 풀링 · 드롭아웃 · 플래튼

| 기법 | 역할 | 코드 |
|---|---|---|
| 맥스 풀링 | 구역 안에서 **가장 큰 값**만 남겨 크기를 줄임(불필요한 정보 간추림) | `MaxPooling2D(pool_size=(2,2))` |
| 평균 풀링 | 구역의 **평균값**을 남김 | (보편적으로는 맥스 풀링을 사용) |
| 드롭아웃 | 은닉층 노드 일부를 임의로 꺼서 **과적합 방지** | `Dropout(0.25)` → 25%의 노드를 끔 |
| 플래튼 | 2차원 배열을 1차원으로 **평탄화**해 Dense 층에 연결 | `Flatten()` |

- 컨볼루션 층·풀링 층은 이미지를 **2차원인 채로** 다루므로, Dense 층에 넣기 전에 `Flatten()`이 필요하다.
- 정확도 비교: 은닉층 하나짜리 모델 **98.16%** → CNN 모델 **99.17%** (테스트 1만 장 중 1,000장 단위로 101장 더 맞힘)

### 4. 객체 인식의 네 단계

| 단계 | 하는 일 |
|---|---|
| 객체 분류(classification) | 이미지가 고양이·개·토끼 중 무엇인지 판별 |
| 분류 + 영역 지정(localization) | 분류한 객체의 영역만 추출(붉은 박스) |
| 객체 탐지(detection) | **경계 상자(bounding box)** 로 영역을 잡고, 그 안의 물체가 무엇인지 판별 (여러 객체) |
| 객체 분할(segmentation) | 객체가 속한 영역과 다른 객체의 영역을 **픽셀 단위**로 나눔 |

- **R-CNN**: 객체가 있을 만한 영역을 선택적으로 탐색 → 정확도는 있지만 2단계를 거쳐 **실시간 처리에 한계**.
- **YOLO**(You Only Look Once, 2015, 조셉 레드몬): 한 번만 보고 매우 빠르고 정확하게 탐지. 자율주행처럼 **정확도 + 신속성**이 필요한 분야에 쓰인다.
