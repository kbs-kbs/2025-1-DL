## 1. RNN의 한계와 문맥 벡터

- RNN은 여러 개의 입력 값을 바로 처리하지 않고 **잠시 기억해 두었다가** 다음 입력의 출력을 결정한다.
- 인코더 → 디코더 구조(예: 번역)에서는 인코더의 **마지막 셀** 값 하나에 문장 전체의 뜻이 함축되어 전달된다. 이 값을 **문맥 벡터(context vector)** 라고 한다.
- 문제는 입력 문장이 길어질 때 생긴다.
  - 앞쪽에서 전달된 결과가 중간에 희미해진다(기울기 소실).
  - 문맥 벡터 하나가 모든 입력 정보를 디코더에 제대로 전달하기 어려워진다.

## 2. 어텐션의 원리

- 인코더와 디코더 **사이에 층을 하나 더** 두고, 각 셀에서 계산된 **스코어**를 모은다.
- 스코어에 **소프트맥스**를 적용해 **어텐션 가중치**를 만든다.
- 가중치를 이용해 "이번 출력 단어를 만들 때 입력의 어떤 셀을 중점적으로 볼지"를 결정한다.
  - 예: 첫 출력 단어 '당신께'에 가장 적절한 입력은 4번째 셀 'you'라는 것을 학습.
- 즉, **매 출력마다 모든 입력 값을 두루 활용**하게 만들어, 마지막 셀에 모든 입력이 집중되던 RNN의 단점을 극복한 알고리즘이다.
- 알파폴드2(2020, 제14회 세계 단백질 구조 예측 대회)의 핵심 축도 어텐션이다.

### 전체 코드 (강의 슬라이드 기준)

```python
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Dense, Dropout, Activation, Embedding, LSTM, Conv1D, MaxPooling1D
from tensorflow.keras.datasets import imdb
from tensorflow.keras.preprocessing import sequence
from tensorflow.keras.callbacks import EarlyStopping
from attention import Attention

import numpy as np
import matplotlib.pyplot as plt

# 데이터를 불러와 학습셋, 테스트셋으로 나눕니다.
(X_train, y_train), (X_test, y_test) = imdb.load_data(num_words=5000)

# 단어의 수를 맞춥니다.
X_train = sequence.pad_sequences(X_train, maxlen=500)
X_test = sequence.pad_sequences(X_test, maxlen=500)

# 모델의 구조를 설정합니다.
model = Sequential()
model.add(Embedding(5000, 500))
model.add(Dropout(0.5))
model.add(LSTM(64, return_sequences=True))   # 어텐션은 시퀀스 전체가 필요하므로 return_sequences=True
model.add(Attention())                       # 인코더-디코더 사이의 스코어/가중치 계산을 대신 수행
model.add(Dropout(0.5))
model.add(Dense(1))
model.add(Activation('sigmoid'))

# 모델의 실행 옵션을 정합니다.
model.compile(loss='binary_crossentropy', optimizer='adam', metrics=['accuracy'])

# 학습의 조기 중단을 설정합니다.
early_stopping_callback = EarlyStopping(monitor='val_loss', patience=3)
```

- `Attention()` 함수가 위 그림의 회색 사각형(스코어 계산 → 소프트맥스 → 가중합)을 처리하므로 코드는 한 줄이면 된다.
- `Attention()` 앞의 LSTM은 **모든 시점의 은닉 상태**를 넘겨야 하므로 `return_sequences=True`가 필요하다.

### 결과

| 모델 | 테스트셋 정확도 |
|---|---|
| LSTM + CNN (6주차) | 84.54% |
| LSTM + **Attention** (7주차) | **88.08%** |

## 4. 정리

| 구분 | RNN | 어텐션 |
|---|---|---|
| 정보 전달 | 마지막 셀의 문맥 벡터 하나 | 모든 셀의 은닉 상태 + 가중치 |
| 긴 문장 | 앞쪽 정보 소실 | 필요한 셀에 집중 |
| 구현 | `LSTM(...)` | `LSTM(..., return_sequences=True)` + `Attention()` |
