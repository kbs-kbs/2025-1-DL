## 1. 코드의 세 부분

폐암 수술 환자 생존율 예측 코드는 세 부분으로 나뉜다.

| 부분 | 코드 | 역할 |
|---|---|---|
| 모델 구조 정의 | `model = Sequential()`, `model.add(...)` | 층을 쌓아 신경망 구조를 짠다 |
| 컴파일 | `model.compile(...)` | 손실 함수·옵티마이저·평가지표를 정해 컴퓨터가 알아듣게 한다 |
| 실행 | `model.fit(...)` | 실제로 학습시킨다 |

```python
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Dense
import numpy as np

Data_set = np.loadtxt("./data/ThoraricSurgery3.csv", delimiter=",")
X = Data_set[:, 0:16]
y = Data_set[:, 16]

model = Sequential()
model.add(Dense(30, input_dim=16, activation='relu'))
model.add(Dense(1, activation='sigmoid'))

model.compile(loss='binary_crossentropy', optimizer='adam', metrics=['accuracy'])
history = model.fit(X, y, epochs=5, batch_size=16)
```

## 2. 입력층 · 은닉층 · 출력층

- `model.add()` 한 줄이 층 하나. 마지막 층이 **출력층**, 나머지는 **은닉층**이다.
  - 위 코드는 층이 2개 → 첫 층 = 은닉층(+입력 역할), 두 번째 = 출력층
- `Dense(30, input_dim=16)`
  - 첫 번째 인자 `30` = 이 층의 **노드 수**(가중합이 모이는 곳)
  - `input_dim=16` = 입력 데이터에서 몇 개의 값을 가져올지. 케라스는 입력층을 따로 만들지 않고 **첫 번째 은닉층에 `input_dim`을 적어 입력층 역할을 겸하게** 한다.
  - 폐암 데이터는 속성이 16개이므로 16개를 받아 30개 노드로 보낸다.
- `Dense(1, activation='sigmoid')`
  - 생존/사망 둘 중 하나를 출력하므로 노드 1개, 활성화 함수는 시그모이드(0~1 확률).

## 3. 모델 컴파일

- **손실 함수**: 학습의 기준. 두 계열이 있다.
  - 평균 제곱 오차 계열(`mean_squared_error`) → **회귀**
  - 교차 엔트로피 계열 → **분류**
    - 이항 분류: `binary_crossentropy` (생존/사망)
    - 다항 분류: `categorical_crossentropy` (0~9 손글씨)
- **옵티마이저**: 현재 가장 많이 쓰는 것은 `adam`.
- **metrics**: `accuracy`(학습셋 정확도), `loss`, 테스트셋을 적용하면 `val_acc`, `val_loss` 등.

## 4. 모델 실행 — epoch와 batch_size

- 폐암 데이터: 470명의 환자 × 16개 정보 → **샘플 470개**, **속성 16개**
  - 샘플 = instance, example / 속성 = 피처(feature), 특성 이라고도 한다.
- **epoch**: 학습 프로세스가 모든 샘플에 대해 한 번 실행되는 것. `epochs=5`는 전체를 5번 반복.
- **batch_size**: 샘플을 한 번에 몇 개씩 처리할지. `batch_size=16`은 470개를 16개씩 끊어 넣는다는 뜻.
  - 너무 크면 학습 속도가 느려지고, 너무 작으면 실행 값의 편차가 커져 결과가 불안정해진다.
  - 메모리가 감당할 만큼의 batch_size를 찾는 것이 좋다.

## 5. 시험 포인트로 자주 나온 부분

- `model.add(Dense(...))` 첫 줄에서 **입력층과 첫 은닉층의 노드 개수**를 읽는 것
- `model.summary()` = 신경망 구조 요약
- `loss='mean_squared_error'` = 숫자 예측(회귀)이기 때문
- `optimizer`는 CNN·RNN·자연어처리 모두 `adam`
